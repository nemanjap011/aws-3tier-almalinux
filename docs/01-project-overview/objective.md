# Project Objective

The objective of this project is to build a production-style 3-tier AWS environment using AlmaLinux and PostgreSQL in order to develop practical Cloud Engineer and Site Reliability Engineering skills.

The project is designed to simulate real-world infrastructure and operations tasks, including:
- network segmentation
- private and public tier design
- Linux server administration
- PostgreSQL service management
- monitoring and validation
- troubleshooting and incident response
- infrastructure as code with Terraform

The final deliverable should demonstrate not only deployment capability, but also operational maturity through documentation, runbooks, validation evidence, and recovery procedures.
